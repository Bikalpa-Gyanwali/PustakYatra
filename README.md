# PustakYatra

PustakYatra is a book discovery web application built to help users search for books, explore book details, discover recommendations, save favorites and wishlist items, and take part in a reader community.

## Features
- Search books and explore detailed book pages
- Get book recommendations
- Register and log in with user accounts
- Save favorites and wishlist items
- Join community discussions around books

## Tech Stack
- Frontend: React, Vite, Tailwind CSS
- Backend: Express.js, MongoDB
- Recommendation System: Python, Flask

## Running Locally
```bash
# frontend
npm install
npm run dev
```

```bash
# backend
cd server
npm install
npm start
```
